# API Test Automation with Pytest

This project demonstrates basic API test automation using Python, pytest, and requests.

It is designed as a junior QA / test analyst portfolio project.

## What This Project Tests

- GET user by valid ID
- GET all users
- POST new post
- Invalid user ID
- Invalid endpoint
- Status code validation
- JSON response validation
- Basic negative testing

## Tools Used

- Python
- pytest
- requests
- GitHub Actions

## How to Run

```bash
pip install -r requirements.txt
pytest
